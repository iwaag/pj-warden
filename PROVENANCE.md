# Provenance

This repository is an edited derivative of warden's internal repository, first published as a single root
commit. The internal history, run records and disposable check workflows are not included. The agents' guides
were rewritten to remove facts specific to the installation they were developed on (host names, run and phase
identifiers). `coordinate.yaml` has had its node pin removed. Dedicated to the public domain under CC0 1.0.
